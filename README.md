 # PTSD & Addiction Prediction Model

## Overview
This project focuses on predicting online gambling and social media addiction using psychological variables such as PTSD, alexithymia, attachment styles, and self-esteem.

## Project Structure

- data/ → dataset (not public due to privacy)
- notebooks/ → analysis and modeling
- models/ → saved models
- results/ → outputs and visualizations

## Methods
- Machine Learning
- Clustering
- Statistical modeling
